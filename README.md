# Degrading-Dream


### Core Mechanics and Gameplay Features:

- **No static hiding spots:**
    - The goal is to have a "honey-like" system
    - Meaning: while the player is crouching next to a potential piece of cover (close to a wall, on a corner, behind an obstacle, etc), the game will automatically put the player into a state of hiding behind it (eg, peeking around a corner, or pressed up against a wall)
- **Lots of movement options**:
    - Moving should feel fluid and easy to improvise on for the player.
    - There should be ways to go fluidly from any state of movement to another (eg, a dive from sprinting to crawling).
    - There should be movement on the Y axis, including jumping, standing upright, crouching, or crawling.
    - X axis movement includes walking, running, and diving.
- **Item Usage:**
    - The player will be able to pick up and use various items such as flashlights, bottles, noisemakers, etc.
    - The quantity of different item types can change depending on available scope.
    - Each item would have a different use or niche to fill. For example, flashlights would be self explanatory but there could be bottles to distract enemies and other items.
    - Given enough time, there could be intractable environment items such as chairs for a height boost, tables that can pushed over for cover, and more.


### Roadmap:

The current goal is to create a small prototype that demonstrates the core gameplay mechanics.

This will consist of:

- A room with at least one type of cover / hiding place for the player.
- An enemy with basic behavior.
- The “honey-like” hiding system implemented.
- Some of the movement mechanics (sprinting and crouching, maybe diving if possible).

Once the prototype is complete, we will expand it out into multiple rooms with a story.
